# YouTube Description

Want to improve your Anki cards faster without manually rewriting everything?

AI Automation is an Anki add-on that lets you use AI directly inside Anki to clean up notes, improve explanations, rewrite card content, and run repeatable workflows across lots of cards.

In this video, I show what the add-on can do and how it works inside Anki, including:

- `Transform with AI` in the Browser
- reusable prompts and system prompts
- saved presets for repeatable runs
- reusable workflows and workflow groups
- single-field and multi-field output
- flexible write modes like `overwrite`, `append`, and `skip if target field not empty`

If you want to make your flashcards clearer, more consistent, and easier to maintain, this add-on is built for exactly that.
