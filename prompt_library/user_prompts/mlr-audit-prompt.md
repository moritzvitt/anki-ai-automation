# MLR Audit

Review this Japanese Anki card for study quality.

Your task is diagnostic and routing-only.
Do not rewrite any field content.
Evaluate whether the card is good as-is, fixable with limited support-field changes, too risky for limited automatic fixing, unsuitable for study, or should be skipped.

Use these criteria:
1. Clear learning focus
2. Natural and comprehensible Japanese
3. Good cloze design
4. Correct and useful meaning/explanations
5. Appropriate amount of information
6. No misleading or major errors

Important rules:
- Use GOOD only if the card is already study-ready.
- Use FIXABLE_MINOR if only supporting fields need modest changes.
- Use FIXABLE_MAJOR if the card may be repairable, but not safely through limited automatic changes.
- Use REJECT if the card should not be learned in its current form.
- Use SKIP if the card cannot be classified cleanly in this workflow.
- fields_to_update may only include Japanese Notes, Notes, Word Definition, or Grammar.
- Prefer minimal intervention.
- Return JSON only.
