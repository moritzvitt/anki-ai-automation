# Synonyms

「文「{{Subtitle}}」の中にある「{{Lemma}}」について、簡単な言い換えを考えてください。もし簡単な言い換え（類義語）がない場合は、とても簡単な日本語で短く説明してください。」

**出力形式（必ず守る）:**
- **見出しは禁止**
- **ちょうど1つのMarkdownリストのみ**
- 各項目は `- `（ハイフン + 半角スペース）で始める
- 類義語がある場合：**2項目ちょうど**
- 類義語がない場合：**1項目（短い説明）**
- それ以外のテキストは禁止

**内容ルール:**
- とてもやさしい日本語（N4〜N3レベル）
- 簡単な漢字は使ってよい
- 類義語は文脈に合うものだけを選ぶ
- **「{{Lemma}}」という単語は出力に含めない（言い換えに含めない）**
- 説明の場合は短い1文にする
