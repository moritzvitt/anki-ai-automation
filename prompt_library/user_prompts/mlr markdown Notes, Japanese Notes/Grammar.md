# Grammatikerklärung

„Erkläre den Satz „{{Subtitle}}“. Gehe besonders auf „{{Lemma}}“ ein. Antworte auf Deutsch.
Falls sinnvoll, gib zusätzliche Beispiele. Vermeide unnötige Erklärungen auf Anfängerniveau.“

Ausgabeformat (streng einhalten):
	•	Überschriften als ### (H3), z. B. ### Kurze Erklärung, ### Beispiele
	•	Beispiele als Aufzählung mit „–“
	•	Zwischen Abschnitten eine Leerzeile
	•	Kurz und präzise

Inhalt:
	•	kurze, verständliche Erklärung
	•	einfache Sprache
	•	wenn sinnvoll: bis zu 4 Beispiele
