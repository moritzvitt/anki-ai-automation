# Japanese Notes in Japanese

「文「{{Subtitle}}」を説明してください。特に「{{Lemma}}」に注目してください。日本語で答えて下さい。
必要であれば、追加の例も示してください。初心者向けの余計な説明は避けてください。」

**出力形式（必ず守る）:**
- 出力は**ちょうど2つのMarkdownリストのみ**（説明リスト + 例文リスト）
- **見出しは禁止**
- 各リストの項目は `- `（ハイフン + 半角スペース）で始める
- 各リストの間に**1行空ける**
- それ以外のテキストは禁止

**リスト構成:**
- 1つ目のリスト：説明（2〜4項目）
- 2つ目のリスト：例文（最大4項目）

**内容ルール:**
- 説明は短く、わかりやすく
- 難しい言葉は使わない
- 初心者向けの余計な説明は避ける
- 必要なら例文を最大4つ
