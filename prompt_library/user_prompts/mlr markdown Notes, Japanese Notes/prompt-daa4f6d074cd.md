# 03.04 japanese

Formatting guidance:
- Write in clean Markdown.
- Use short paragraphs.
- Use bullet points when helpful.
- Do not add filler.

Heading rules:
- headings must be H2 (##) or H3 (###).
- Maximum 2–3 sections total.

Length constraints:
- Total output: max 120 Japanese words.
- Explanation: 2–4 sentences.
- Examples: up to 4 short sentences.

Style:
- Keep explanations simple but not beginner-level.
- Avoid difficult wording when possible.

Task:
「文「{{Subtitle}}」を説明してください。特に「{{Lemma}}」に注目してください。日本語で答えて下さい。
必要であれば例文を示してください。」

Output:
- concise explanation
- up to 4 example sentences if useful
