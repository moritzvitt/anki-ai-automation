# 03.04 japanese as markdown

## Task
文「{{Subtitle}}」を説明してください。特に「{{Lemma}}」に注目してください。日本語で答えて下さい。必要であれば例文を示してください。

## Output Requirements
- 簡潔な説明（2〜4文）
- 必要に応じて例文（最大4文）

## Formatting Guidelines
- Markdownで出力すること
- 短い段落で書くこと
- 必要に応じて箇条書きを使うこと
- 無駄な説明は省くこと

## Heading Rules
- 見出しは H2 (##) または H3 (###) のみ使用
- セクション数は最大2〜3まで

## Length Constraints
- 全体：最大120語（日本語）
- 説明：2〜4文
- 例文：最大4つの短文

## Style
- シンプルだが初級すぎない説明
- 難しすぎる表現は避ける
