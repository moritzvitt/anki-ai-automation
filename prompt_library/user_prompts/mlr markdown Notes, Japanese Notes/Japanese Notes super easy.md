# Japanese Notes Super Easy

「文「{{Subtitle}}」と「{{Lemma}}」を、とても簡単な日本語で説明してください。難しい言葉や文法用語は使わないでください。簡単な漢字は使ってもいいです。」

**出力形式（必ず守る）:**
- H3見出し（`###`）を使う（例：`### 説明`）
- その下に**ちょうど1つのMarkdownリスト**
- 各項目は `- `（ハイフン + 半角スペース）で始める
- 合計で**最大3項目（＝最大3文）**
- それ以外のテキストは禁止

**内容ルール:**
- とてもやさしい日本語（N4〜N3レベル）
- 簡単な漢字は使ってよい（難しい言葉は使わない）
- 文全体の意味を簡単に説明する
- 「{{Lemma}}」の意味もやさしく説明する
- 必要なら短い例を1つだけ含めてもよい
